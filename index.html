設定教學
1
建立 Google 試算表
前往 sheets.google.com 建立新試算表，建立四個工作表分頁：
trips  itinerary  budget  checklist
複製網址列中 /d/ 和 /edit 之間的 ID 字串。
2
Google Cloud Console 建立專案
前往 console.cloud.google.com
點「選取專案」→「新增專案」→ 命名後建立。
3
啟用 API
左側選單 → API 和服務 → 資料庫
搜尋並啟用：Google Sheets API 和 Google Drive API
4
建立 OAuth 用戶端 ID
左側 → 憑證 → 建立憑證 → OAuth 用戶端 ID
▸ 應用程式類型：網頁應用程式
▸ 授權的 JavaScript 來源：http://localhost 和你的 Vercel 網址
▸ 完成後複製 Client ID 貼入上方欄位
5
設定同意畫面（只需一次）
若要求設定同意畫面：
▸ 用戶類型選「外部」→ 建立
▸ 填入應用程式名稱（例：旅途規劃）
▸ 新增測試使用者：填入自己的 Gmail
▸ 儲存並繼續（不需送審，個人使用測試模式即可）
6
完成！點「Google 登入授權」
將 Client ID 和試算表 ID 填入上方 → 點「Google 登入授權」
第一次會跳出 Google 授權視窗，允許後即可同步資料。
之後每次開啟網頁會自動保持登入狀態。
